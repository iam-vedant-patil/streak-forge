# 🔥 Streak Forge

A smart daily streak tracker designed to help users build consistency through daily action.

## Features

- Daily task tracking
- Automatic task categorization
- Keyword-based task recognition
- Persistent keyword storage
- Daily streak tracking
- Motivational quotes and UX feedback
- Progress and streak history

## Tech Stack

- **Frontend:** React + Vite
- **Backend:** Python + FastAPI
- **Database:** SQLite
- **Version Control:** Git + GitHub
